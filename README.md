## Descripcion

Este proyecto consiste en el desarrollo de una aplicación web de gestión de proyectos educativos utilizando **React y Vite**. La aplicación permite **visualizar, agregar, buscar y eliminar proyectos** de manera dinámica mediante el uso de **componentes reutilizables, hooks y módulos de servicios.**

Se aplicaron conceptos fundamentales de React como **JSX, componentes funcionales, manejo de estado con useState y organización modular del código** . Ademas, para le gestion de dependencias
y ejecucion del proyecto se uso **pnpm** en lugar de npm.
